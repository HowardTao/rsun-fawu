# 09: 核定案件关联委托、冻结与联系单的最小契约

Status: ready-for-agent

**Parent:** [完整重建总规格](../../fawu-rebuild/spec.md)；[案件完整链路分规格](../../case-lifecycle/spec.md)

**工作类型：** 核验

**What to build:** 核定案件试点实际需要的律师/合同来源、委托阶段关系、冻结关联和联系单申请/协办/验收用例。

**Blocked by:** [01 核实测试环境、隔离目标与确认职责](01-environment-baseline.md)。

**规格覆盖：** V09、V11；C-37～38；TC-18。

**事实与规则来源：** [前置核验清单](../../fawu-rebuild/verification-checklist.md)；[关联业务代表路径](../../fawu-rebuild/remaining-business-workflows.md)；[范围清单](../../fawu-rebuild/scope-review.md)。

## Acceptance criteria

- [ ] 三个关联分别有样本、字段、操作范围和所属模块成果。
- [ ] 现有来源与必要审批明确。
- [ ] 不把审批同意等同费用结清或联系单办结，不声称整域核验完成。

## 执行边界

本任务交付核验事实和结论，不实现后续业务功能。保留来源、样本、期望/实际、差异及确认职责；缺访问或材料时记录具体缺口，不能把未核实内容当通过。涉及写回的测试仅使用已经明确的可恢复副本或隔离目标。
