# 上线、部署与维护约束

关联事项：[确认上线、部署和维护硬约束](issues/06-delivery-deployment-constraints.md)。

## 已确认与待确认

| 事项 | 已确认 | 尚待明确 |
| --- | --- | --- |
| 新系统部署位置 | 公司内网自管服务器 | 具体服务器资源和部署操作安排 |
| 操作系统 | 主应用已选 Ubuntu 24.04 LTS + Nginx，同域托管 | 旧集成组件兼容、数据库宿主与运维支持 |
| 数据库 | 新业务库已更正为 PostgreSQL，用户顾虑 SQL Server 可能涉及许可问题；未提出禁止保留旧库或其他软件的采购要求 | 旧库实际版本与依赖、PostgreSQL 版本和迁移、旧库共存期间的许可安排 |
| 上线时间 | 暂无硬截止日期；期望 2026 年底上线 | 根据完整业务、集成、迁移验证与可投入人力形成计划 |
| 开发能力 | 开发人员熟悉 Element UI 与 .NET | 开发人数、评审投入及前端技术迁移适应成本 |
| AI 与人工分工 | AI Agent 主要负责实现，开发人员评审；集团法务和业务经办人可定期参与流程验证、迁移核对与验收 | 具体评审人员、人数及时间投入仍未量化 |
| 旧系统验证资源 | 有可用的 Windows 测试环境 | 本次尚未连接；接口、数据库及流程验证的具体使用条件 |
| 网络、采购与运维 | 用户确认能联网、无访问限制；公司有专门 IT 负责运维；没有许可和采购限制 | 部署时实际端点连通验证、运维职责细分及备份恢复安排 |

年底作为期望时间记录，当前尚未形成可验证的工期估算或上线承诺。首期十组业务的完整覆盖要求见[范围清单](scope-review.md)。

## 技术候选的当前状态

- [既有技术研究](research/rebuild-technology-options.md)已核实 .NET 10 LTS 支持期及现代 ASP.NET Core 的部署候选；该报告保留研究时状态，当前选择以技术路线事项为准。
- [技术候选补充核对](research/technology-candidate-followup.md)已提供 Vue 3 / Element Plus、.NET 10 支持的 Ubuntu LTS、SQL Server/PostgreSQL 的官方材料及版本核验前提。
- 用户于 2026-10-22 确认 .NET 10 LTS + Vue 3 / Element Plus、单个后端应用按业务模块组织；Q41 更正为 PostgreSQL。部署采用 Ubuntu 24.04 LTS + Nginx 同域入口，必要时允许经验证的 Windows 集成过渡进程，详见[技术路线事项](issues/07-architecture-technology-decision.md)。
- 具体数据库、驱动与组件版本及运行兼容仍需锁定验证。

## 后续核验与排期输入

- 网络无访问限制是用户给出的部署约束，不代替实际环境的连通验证。
- 公司 IT 负责运维，具体应用、服务器、数据库、备份恢复的责任细分与演练安排在部署和切换决策中落实。
- 开发评审人数及时数尚未量化，业务方已确认能定期参与；工期估算前需落实可投入资源。
- 客户端浏览器、第三方组件支持及数据库实际版本继续核验；历史迁移与切换条件仍待相关决策。
