# 领域文档

本工程采用 single-context 布局：根目录的 `GLOSSARY.md` 保存领域词汇，`docs/adr/` 保存架构决策。

## 探索前读取

- 读取根目录的 `GLOSSARY.md`。
- 读取 `docs/adr/` 中与当前工作相关的决策记录。
- 文件或目录不存在时直接继续；不因缺失而主动建议创建。
- `/domain-modeling` 在术语或决策实际明确后，按需创建这些文档。

## 使用领域词汇

在任务标题、方案、假设和测试名称中，使用 `GLOSSARY.md` 定义的领域术语。

需要的概念尚未收录时，先检查是否引入了项目不用的词；确有缺口时，记录为待领域建模澄清的问题。

## 报告决策冲突

方案与现有 ADR 冲突时，必须明确指出所冲突的决策及重新讨论的理由，交由用户决定。
